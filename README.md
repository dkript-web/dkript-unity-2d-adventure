# Dkript2DAdventure (dkript-unity-2d-adventure)

Repositorio público oficial del proyecto ejecutable de Unity para el curso práctico de desarrollo de videojuegos de plataformas 2D desde cero, creado por **Joel Jonathan Perez Delgado / Dkript**.

---

## 🎯 Propósito del Proyecto

Este repositorio contiene el proyecto funcional en Unity y C#, diseñado para que estudiantes, desarrolladores y personas interesadas puedan clonar, abrir y probar el código de cada etapa del curso en su propio equipo.

El material audiovisual complementario de cada etapa se publica a través de YouTube, y la evolución del código se encuentra organizada mediante ramas funcionales por hito.

---

## ⚙️ Requisitos Técnicos y Versión de Unity

| Componente | Configuración Oficial |
| :--- | :--- |
| **Versión del Editor** | `Unity 6000.6.8f1` (Unity 6.6 LTS) |
| **Pipeline Gráfico** | Universal 2D (URP 2D - `com.unity.render-pipelines.universal` v17.0.4) |
| **Sistema de Entrada** | Unity Input System (`com.unity.inputsystem` v1.19.0) |
| **Paquetes 2D** | 2D Feature Set (`com.unity.feature.2d` v2.0.1) |

## 🚀 Cómo Clonar y Abrir el Proyecto

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/dkript-web/dkript-unity-2d-adventure.git
   cd dkript-unity-2d-adventure
   ```

2. **Abrir en Unity Hub:**
   - Inicia **Unity Hub**.
   - Haz clic en el botón **Add** (o *Add project from disk*).
   - Selecciona la carpeta del proyecto clonado.
   - Asegúrate de tener instalada la versión **Unity 6000.6.8f1**.
   - Haz clic sobre el proyecto en la lista para abrir el Unity Editor.

3. **Cargar la escena del hito actual:**
   - Ve a la ventana **Project**: `Assets/_Project/Scenes/`.
   - Haz doble clic sobre `Stage00_Setup.unity`.
   - Presiona el botón **Play (▶)** para comprobar el arranque del proyecto en la **Consola**.

## 🌿 Ramas de Código por Etapa (Git Branches)

El proyecto utiliza ramas dedicadas para congelar cada etapa funcional del curso:

| Rama | Etapa / Contenido | Escena Principal | Video en YouTube |
| :--- | :--- | :--- | :--- |
| `main` | Rama principal del proyecto ejecutable | `Assets/_Project/Scenes/Stage00_Setup.unity` | [Canal Oficial](https://www.youtube.com/) |
| `stage/00-setup` | Preparación de entorno y script de diagnóstico base | `Stage00_Setup.unity` | Próximo estreno |
| `stage/01-sprites` | Importación de sprites y montaje visual de personaje | `Stage01_Sprites.unity` | Próximo estreno |
| `stage/02-tilemaps` | Construcción de escenarios 2D con Tilemaps | `Stage02_Tilemaps.unity` | Próximo estreno |
| `stage/03-collisions` | Colisiones físicas y controladores de movimiento 2D | `Stage03_Collisions.unity` | Próximo estreno |
